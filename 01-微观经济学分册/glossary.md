# 术语表

| 术语 | 白话定义 | 首次出现 |
|---|---|---|
| 权衡取舍 | 多要一样东西就必须少要另一样，两个都想要的目标之间的此消彼长。 | ch01 |
| 机会成本 | 为了得到某样东西而放弃的东西的价值，包括账面支出和放弃的收益。 | ch01 |
| 理性人 | 在可选范围内系统比较成本与收益、追求净收益最大的人；书里是分析起点，不是对真实人的道德评价。 | ch01 |
| 边际变动 | 在现有基础上再多一单位或少一单位所带来的变化。 | ch01 |
| 激励 | 能改变人行为的东西，如价格、奖励、惩罚、规则。 | ch01 |
| 市场 | 买卖双方自发交换的场所与规则，靠价格传递稀缺信息。 | ch01 |
| 产权 | 对某项资源归谁所有、如何使用、收益归谁的界定。 | ch01 |
| 外部性 | 一个人的行为给旁观者带来成本或好处，而价格没有把这笔账算进去。 | ch01 |
| 生产率 | 平均每个工人每小时生产的物品与服务量。 | ch01 |
| 通货膨胀 | 经济中物价总水平的普遍上涨，不是某几样商品涨价。 | ch01 |
| 生产可能性边界 | 在既定资源与技术下，经济能生产的两种产品的最大组合所连成的曲线。 | ch02 |
| 循环流量图 | 把家庭与企业、物品市场与要素市场连成循环，用来展示收入与支出如何流动的模型。 | ch02 |
| 微观经济学 | 研究单个决策者（家庭、企业）与单个市场如何配置资源。 | ch02 |
| 宏观经济学 | 研究整体经济现象，如通胀、失业、经济增长。 | ch02 |
| 实证分析 | 描述世界是什么样、某政策会导致什么结果，可用事实检验对错。 | ch02 |
| 规范分析 | 判断世界应该是什么样，包含价值判断，不能仅靠事实裁决。 | ch02 |
| 效率 | 在既定资源下把总收益做到最大、或把浪费降到最小的状态。 | ch02 |
| 增长 | 生产能力本身扩大，表现为生产可能性边界向外移动。 | ch02 |
| 绝对优势 | 用相同的资源投入，能生产出更多某种产品的能力。 | ch03 |
| 比较优势 | 生产某种产品的机会成本低于他人的能力；决定分工的依据。 | ch03 |
| 机会成本 | 为生产一单位某产品而放弃的另一产品的数量。 | ch03 |
| 世界价格 | 世界市场上一种产品的通行价格，是国内是否出口或进口的判断基准。 | ch03 |
| 专业化 | 把资源集中用于自己机会成本最低的产品生产。 | ch03 |
| 市场 | 买者与卖者交换某种物品或服务的场所与规则。 | ch04 |
| 竞争市场 | 买卖者众多、产品基本相同、进出自由，任何单个参与者都无法影响价格的市场。 | ch04 |
| 需求量 | 在某一具体价格下，买者愿意并且能够购买的数量。 | ch04 |
| 需求法则 | 其他条件不变时，价格上升则需求量下降。 | ch04 |
| 供给量 | 在某一具体价格下，卖者愿意并且能够出售的数量。 | ch04 |
| 供给法则 | 其他条件不变时，价格上升则供给量增加。 | ch04 |
| 均衡 | 供给量等于需求量、市场没有过剩也没有短缺的状态。 | ch04 |
| 过剩 | 供给量大于需求量的状态，价格有下降压力。 | ch04 |
| 短缺 | 需求量大于供给量的状态，价格有上升压力。 | ch04 |
| 替代品 | 一种商品价格上升会使另一种商品需求增加的商品对，如咖啡与奶茶。 | ch04 |
| 互补品 | 一种商品价格上升会使另一种商品需求减少的商品对，如奶茶与珍珠。 | ch04 |
| 弹性 | 一个变量对另一个变量变化的敏感程度，用百分比之比衡量。 | ch05 |
| 需求价格弹性 | 需求量变动百分比与价格变动百分比之比。 | ch05 |
| 中点法 | 用区间两端平均值作分母计算百分比变动，避免起点不同导致结果不同。 | ch05 |
| 富有弹性 | 弹性绝对值大于 1，需求量对价格反应强烈。 | ch05 |
| 缺乏弹性 | 弹性绝对值小于 1，需求量对价格反应微弱。 | ch05 |
| 总收益 | 价格乘以销售数量，等于买者的总支出。 | ch05 |
| 收入弹性 | 需求量变动百分比与收入变动百分比之比，用于判断正常品与劣等品。 | ch05 |
| 交叉价格弹性 | 一种商品需求量变动百分比与另一种商品价格变动百分比之比，正值多为替代品，负值多为互补品。 | ch05 |
| 供给价格弹性 | 供给量变动百分比与价格变动百分比之比，主要受时间长短影响。 | ch05 |
| 价格上限 | 法律规定的最高售价，只有低于均衡价时才有约束力。 | ch06 |
| 价格下限 | 法律规定的最低售价，只有高于均衡价时才有约束力。 | ch06 |
| 配给机制 | 价格不能出清时用于分配稀缺商品的办法，如排队、抽签、凭票、凭关系。 | ch06 |
| 税收归宿 | 税收负担最终由谁承担，由供需弹性决定，与法律规定的纳税人无关。 | ch06 |
| 税收楔子 | 买者支付的价格与卖者得到的价格之间的差额。 | ch06 |
| 支付意愿 | 买者为一件物品最多愿意支付的金额。 | ch07 |
| 消费者剩余 | 支付意愿减去实际支付，衡量买者从交易中获得的好处。 | ch07 |
| 成本 | 卖者为生产一单位产品愿意接受的最低价格，等于其机会成本。 | ch07 |
| 生产者剩余 | 卖者实际得到的价格减去其成本。 | ch07 |
| 总剩余 | 消费者剩余与生产者剩余之和，衡量市场创造的总价值。 | ch07 |
| 效率 | 在既定资源下使总剩余最大，不浪费任何一方有得有失的交易机会。 | ch07 |
| 市场失灵 | 市场自身无法实现总剩余最大，常见于市场势力与外部性。 | ch07 |
| 无谓损失 | 税收使交易量减少而凭空消失的那部分总剩余，买卖双方与政府都没得到。 | ch08 |
| 拉弗曲线 | 税额与税收收入之间的关系曲线，呈倒 U 形。 | ch08 |
| 税基 | 被征税的对象范围，如某类商品的全部销售额。 | ch08 |
| 世界价格 | 世界市场上该商品的通行价格，决定一国出口还是进口。 | ch09 |
| 关税 | 对进口商品征收的税，使国内价格高于世界价格。 | ch09 |
| 进口配额 | 对进口数量的直接限制，效果与关税类似但政府得不到关税收入。 | ch09 |
| 幼稚产业论 | 主张对新兴产业发展初期给予保护，成熟后再参与国际竞争。 | ch09 |
| 调整援助 | 对因贸易受损的工人和企业提供的救济、培训与搬迁支持。 | ch09 |
| 外部性 | 一个人的行为对旁观者福利造成的影响，且未通过市场价格反映。 | ch10 |
| 负外部性 | 行为给旁观者带来成本，社会成本高于私人成本，市场会过量生产。 | ch10 |
| 正外部性 | 行为给旁观者带来收益，社会价值高于私人价值，市场会生产不足。 | ch10 |
| 矫正税 | 按每单位外部成本征收的税，使私人成本等于社会成本，也称庇古税。 | ch10 |
| 可交易许可证 | 政府设定排放总量并发放可买卖的许可，由市场决定谁减排。 | ch10 |
| 科斯定理 | 产权清楚且交易成本足够低时，当事人谈判可达到有效率结果，与产权初始归属无关。 | ch10 |
| 排他性 | 能否阻止不付费的人使用某物品。 | ch11 |
| 竞争性 | 一个人使用某物品是否会减少他人可用的数量。 | ch11 |
| 公共物品 | 既无排他性也无竞争性的物品，如国防、路灯。 | ch11 |
| 公共资源 | 无排他性但有竞争性的物品，如公海鱼群、拥堵道路。 | ch11 |
| 俱乐部物品 | 有排他性但无竞争性的物品，如收费公路、有线电视。 | ch11 |
| 搭便车 | 不承担成本却享用公共物品收益的行为。 | ch11 |
| 公地悲剧 | 公共资源因无排他性被过度使用而枯竭的现象。 | ch11 |
| 平均税率 | 总税额除以总收入，衡量整体负担。 | ch12 |
| 边际税率 | 新增一单位收入所适用的税率，决定额外工作的激励。 | ch12 |
| 受益原则 | 按从公共支出中受益的多少来分摊税负。 | ch12 |
| 支付能力原则 | 按纳税能力分摊税负，能力强者多缴。 | ch12 |
| 纵向公平 | 收入不同的人缴税不同，高收入者多缴。 | ch12 |
| 横向公平 | 处境相同的人应缴相同的税。 | ch12 |
| 累进税 | 税额占收入比重随收入上升而上升的税制。 | ch12 |
| 累退税 | 税额占收入比重随收入上升而下降的税制。 | ch12 |
| 总成本 | 生产一定数量产品所投入的全部资源的成本，包括显性与隐性成本。 | ch13 |
| 显性成本 | 实际付出现金的成本，如原料、工资、租金。 | ch13 |
| 隐性成本 | 未付出现金但确实放弃的收益，如自有资金的机会成本、业主的时间。 | ch13 |
| 经济利润 | 总收益减去全部成本（显性加隐性）。 | ch13 |
| 会计利润 | 总收益减去显性成本。 | ch13 |
| 边际产量 | 多投入一单位可变要素所增加的产出。 | ch13 |
| 边际成本 | 多生产一单位产品所增加的总成本。 | ch13 |
| 平均总成本 | 总成本除以产量。 | ch13 |
| 规模经济 | 产量扩大使长期平均总成本下降的现象。 | ch13 |
| 价格接受者 | 无法影响市场价格、只能按市场价出售的企业。 | ch14 |
| 边际收益 | 多售出一单位产品所增加的总收益。 | ch14 |
| 利润最大化条件 | 边际收益等于边际成本；竞争企业即价格等于边际成本。 | ch14 |
| 停业点 | 价格低于平均可变成本最低点时，企业暂时停止生产。 | ch14 |
| 沉没成本 | 已经发生且无法收回的成本，不影响当前决策。 | ch14 |
| 正常利润 | 经济利润为零时的回报水平，等于资源在其他用途上能获得的收益。 | ch14 |
| 垄断 | 一家企业独占市场，且存在其他企业难以进入的壁垒。 | ch15 |
| 自然垄断 | 因规模经济使一家企业供货成本最低而形成的垄断，如电网、自来水。 | ch15 |
| 价格歧视 | 对成本相同的商品向不同买者收取不同价格。 | ch15 |
| 寻租 | 企业花费资源游说、诉讼以维持垄断地位，这部分支出不创造产出。 | ch15 |
| 反托拉斯法 | 旨在限制垄断行为、维护竞争的法规。 | ch15 |
| 垄断竞争 | 许多企业销售有差别的产品、可自由进出的市场结构。 | ch16 |

| 寡头 | 少数几家企业主导、彼此高度依赖的市场结构。 | ch17 |
| 卡特尔 | 企业之间就产量与价格达成的同盟，如 OPEC。 | ch17 |

| 派生需求 | 对生产要素的需求由对最终产品的需求派生而来。 | ch18 |

| 人力资本 | 劳动者通过教育、培训、经验积累形成的生产能力。 | ch18 |
