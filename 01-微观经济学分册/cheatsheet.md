# 速查表（微观）

## 核心公式
| 场景 | 内容 |
|---|---|
| 均衡 | Qd = Qs，解得 P* 与 Q* |
| 需求价格弹性 | E = (ΔQ/Q) ÷ (ΔP/P)；>1 富有弹性 |
| 收益 | TR = P × Q；弹性 <1 时涨价增收 |
| 消费者剩余 | 支付意愿 − 实际支付（需求线以上、价格线以下面积） |
| 生产者剩余 | 实际收入 − 成本（价格线以下、供给线以上面积） |
| 税收收入 | 税额 × 税后成交量 |
| 无谓损失 | 楔子造成的三角形面积，随弹性增大而增大 |
| 经济利润 | 总收益 − 显性成本 − 隐性成本 |
| 利润最大化 | MR = MC；竞争企业 P = MC |
| 平均成本 | ATC = TC/Q；MC 穿过 ATC 最低点 |
| 垄断 MR | 线性需求 P = a − bQ 时 MR = a − 2bQ |
| 边际产量值 | VMPL = MPL × P；雇到 VMPL = 工资 |
| 消费者最优 | MRS = Px/Py |

## 常约定量示例（全书统一）
- 需求 Qd = 60 − 2P，供给 Qs = 2P − 20 → 均衡 20 元、20 杯。
- 6 元税 → 买者付 23、卖者得 17、成交量 14、税收 84、无谓损失 18。
- 3 元关税（世界价 15 提到 18）→ 进口从 16 降到 8、关税收入 24、无谓损失 18。
- 4 元负外部性 → 社会最优 Q = 16、P = 22、无谓损失 8。
- 垄断 D: P = 30 − 0.5Q、MC: P = 10 + Q → Q = 10、P = 25；竞争 Q ≈ 13.3、P ≈ 16.7。

## 判断流程
1. 这是哪种市场结构？（数量、差别、壁垒）
2. 有没有外部性、公共物品、信息不对称？（市场失灵检查）
3. 决策者面对的是边际问题还是总量问题？
4. 谁弹性小，谁就多承担成本。

## 常见数值记忆
- 弹性 = 1 时总收入最大。
- 税收收入先增后减（拉弗曲线形状），峰值在中等税率。
- 垄断价格高于竞争、产量低于竞争，差额造成无谓损失。
- 垄断竞争长期：P = ATC > MC，产量低于效率规模。
