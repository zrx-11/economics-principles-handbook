# 术语表

| 术语 | 白话定义 | 首次出现 |
|---|---|---|
| 国内生产总值 | 一国境内一定时期内生产的所有最终物品与服务的市场价值。 | ch23 |
| 最终产品 | 直接供最终使用、不再作为其他产品投入的产品。 | ch23 |
| 名义 GDP | 按当期价格计算的 GDP。 | ch23 |
| 实际 GDP | 按基年价格计算的 GDP，剔除价格变动影响。 | ch23 |
| GDP 平减指数 | 名义 GDP 与实际 GDP 之比乘以 100，衡量整体价格水平。 | ch23 |
| 消费物价指数 | 用固定一篮子消费品价格计算的物价指数，衡量生活费用变化。 | ch24 |
| 通货膨胀率 | 物价指数在两个时期之间的百分比变化。 | ch24 |
| 指数化 | 按物价指数自动调整金额，以维持实际购买力。 | ch24 |
| 名义利率 | 未扣除通胀的挂牌利率。 | ch24 |
| 实际利率 | 名义利率扣除通胀后的购买力增长，近似等于名义利率减通胀率。 | ch24 |
| 生产率 | 每单位劳动投入所生产的产出量。 | ch25 |
| 物质资本 | 用于生产的设备、厂房与基础设施。 | ch25 |
| 人力资本 | 劳动者通过教育、培训与经验积累的知识与技能。 | ch25 |
| 技术知识 | 关于如何生产的知识本身，存在于专利、文献与工艺中。 | ch25 |
| 追赶效应 | 资本存量低的穷国增长更快，因为资本边际收益更高。 | ch25 |
| 债券 | 借款人承诺按期付息还本的债务凭证。 | ch26 |
| 股票 | 对企业所有权的份额，持有人分享剩余收益。 | ch26 |
| 金融中介 | 连接储蓄者与借款人的机构，如银行、共同基金。 | ch26 |
| 可贷资金市场 | 储蓄供给与投资需求相互作用决定利率的市场模型。 | ch26 |
| 挤出效应 | 政府借款抬高利率、减少私人投资的现象。 | ch26 |
| 共同基金 | 汇集众多投资者资金、由专业经理投资于组合的机构。 | ch26 |
| 现值 | 未来一笔金额按某一利率折算成的今天价值。 | ch27 |
| 净现值 | 未来现金流的现值减去初始投入。 | ch27 |
| 风险厌恶 | 偏好确定收益、回避波动的倾向。 | ch27 |
| 多元化 | 把资金投入不相关资产以降低企业特有风险。 | ch27 |
| 基本面分析 | 通过估算资产未来现金流的现值来判断其价值。 | ch27 |
| 有效市场假说 | 资产价格已充分反映所有公开信息的理论。 | ch27 |
| 泡沫 | 资产价格远超其基本面价值的现象。 | ch27 |
| 劳动力 | 就业者与失业者的总和。 | ch28 |
| 失业率 | 失业人数占劳动力的比例。 | ch28 |
| 劳动参与率 | 劳动力占成年人口的比例。 | ch28 |
| 摩擦性失业 | 换工作或初入职场期间寻找匹配岗位造成的失业。 | ch28 |
| 结构性失业 | 技能或地区与岗位需求不匹配造成的失业。 | ch28 |
| 周期性失业 | 经济衰退中总需求不足造成的失业。 | ch28 |
| 自然失业率 | 摩擦性与结构性失业对应的正常失业水平。 | ch28 |
| 失业保险 | 向失业者提供部分收入补偿的制度。 | ch28 |
| 货币 | 被广泛接受用作交换媒介、计价单位与价值储藏的东西。 | ch29 |
| 流动性 | 资产转换为交换媒介的容易程度。 | ch29 |
| 商品货币 | 自身具有内在价值的货币，如金银。 | ch29 |
| 法定货币 | 没有内在价值、依靠政府法令与信任流通的货币。 | ch29 |
| 准备金 | 银行保留的不贷出的存款部分。 | ch29 |
| 准备金率 | 准备金占存款的比例。 | ch29 |
| 货币乘数 | 准备金率倒数，表示单位准备金能支撑的存款总额。 | ch29 |
| 公开市场操作 | 央行买卖政府债券以调节银行体系准备金与货币供给。 | ch29 |
| 货币数量论 | 用 MV = PY 说明物价水平由货币量决定的理论。 | ch30 |
| 流通速度 | 单位货币在一年内参与交易的次数。 | ch30 |
| 通胀税 | 政府通过印钞融资，使持币者购买力下降所形成的隐性税负。 | ch30 |
| 费雪效应 | 名义利率随预期通胀同向调整的现象。 | ch30 |
| 皮鞋成本 | 为减少持有现金的损失而频繁取现所耗费的时间与资源。 | ch30 |
| 菜单成本 | 因改价而发生的重印、更新与沟通成本。 | ch30 |
| 恶性通胀 | 物价极高速上涨、货币失去基本职能的极端通胀。 | ch30 |
| 净出口 | 出口减进口，也称贸易余额。 | ch31 |
| 资本净流出 | 本国居民购买外国资产减去外国人购买本国资产。 | ch31 |
| 名义汇率 | 两种货币之间的兑换比率。 | ch31 |
| 实际汇率 | 两国商品的相对价格，等于名义汇率乘以两国物价之比。 | ch31 |
| 购买力平价 | 同样商品在各国换算后应价格相同的理论。 | ch31 |
| 升值 | 本币能兑换更多外币。 | ch31 |
| 外汇市场 | 本币与外币相互兑换的市场，供求决定汇率。 | ch32 |
| 资本外逃 | 投资者因对一国失去信心而大规模转移资金。 | ch32 |
| 贸易政策 | 关税、配额、补贴等限制或鼓励进出口的政策。 | ch32 |
| 总需求 | 物价水平与总产出需求量之间的关系。 | ch33 |
| 总供给 | 物价水平与总产出供给量之间的关系。 | ch33 |
| 自然产出率 | 经济在正常运转时能生产的产出水平，由要素与技术决定。 | ch33 |
| 滞胀 | 产量下降与物价上涨同时出现的状态。 | ch33 |
| 粘性工资 | 名义工资因合同或习惯不能随物价立即调整。 | ch33 |
| 流动性偏好 | 人们偏好持有流动性高的资产，该理论用货币供求解释利率。 | ch34 |
| 支出乘数 | 政府购买增加引起的总需求变化倍数，等于 1/(1−MPC)。 | ch34 |
| 税收乘数 | 减税引起的总需求变化倍数，等于 −MPC/(1−MPC)。 | ch34 |
| 挤出效应 | 政府借款抬高利率从而减少私人投资的现象。 | ch34 |
| 自动稳定器 | 不需政策决策即随经济状况自动调节税收与支出的机制。 | ch34 |
| 边际消费倾向 | 收入每增加一单位用于消费的比例。 | ch34 |
| 菲利普斯曲线 | 通货膨胀率与失业率之间关系的曲线。 | ch35 |
| 自然率假说 | 失业最终回到自然失业率、不受通胀水平影响的观点。 | ch35 |
| 牺牲率 | 降低一个百分点通胀所损失的年度产出百分比。 | ch35 |
| 反通货膨胀 | 刻意降低通货膨胀率的政策过程。 | ch35 |
| 滞胀 | 通胀上升与失业上升并存的状态。 | ch35 |
| 相机抉择 | 根据当时形势灵活决定政策，而非按固定规则行事。 | ch36 |
| 自动稳定器 | 无需决策即随经济周期自动调节收支的机制。 | ch36 |
| 周期性赤字 | 经济衰退导致税收减少、支出增加所形成的赤字。 | ch36 |
| 结构性赤字 | 剔除周期因素后仍存在的长期收支缺口。 | ch36 |
