# 模式与框架库（宏观）

## 框架一：长期与短期分开看
**何时用**：任何"某政策有没有用"的问题，第一句先问：看多长？
**怎么用**：长期用生产能力（资本、劳动、技术）判断，短期用总需求判断。货币中性只在长期成立，乘数效应只在短期有效。

## 框架二：政策推演四步
1. 政策改变了什么（货币量、政府支出、税率、资本流动）？
2. 它先影响哪个市场（可贷资金、外汇、货币市场）？
3. 价格变量怎么变（利率、汇率）？
4. 通过价格变量影响哪个实体变量（投资、净出口、产量）？

四步走完，链条不会漏环节。第 32、34 章的所有推演都是这个套路。

## 框架三：恒等式先算总量
遇到"这个政策会不会改变贸易余额/储蓄/投资"，先用恒等式：
- 封闭经济：S = I
- 开放经济：NX = S − I
- 货币：MV = PY

恒等式不告诉你方向，但立刻告诉你"什么东西不可能变"。贸易政策不可能改变 NX 总量，就是恒等式的直接结论。

## 框架四：预期是分水岭
同样的政策，预期到与没预期到，效果完全不同。
- 反通胀：预期跟上则代价小，跟不上则代价大（牺牲率）。
- 财政刺激：家庭若预期未来增税，会多储蓄，乘数变小（李嘉图等价的经验版本）。

## 决策规则
- 若通胀高且失业低 → 需求过热，紧缩总需求。
- 若通胀高且失业高 → 滞胀，供给冲击，没有单一解药。
- 若通胀低且失业高 → 需求不足，扩张总需求（注意时滞）。
- 若长期增长停滞 → 看生产率四项，而不是短期刺激。

## 反模式（作者明确提示的误判）
- **把名义当实际**：名义工资涨 5%、物价涨 6%，实际是降薪。
- **把单品涨价当通胀**：通胀是普遍价格水平上升。
- **把长期问题用短期工具解决**：刺激不能提高潜在增长率。
- **忽视时滞做积极调控**：等政策见效时，周期可能已经转向。
- **用总量掩盖分配**：GDP 与通胀率都不回答"谁受损"。
- **把相关当因果**：货币增长与通胀同向，但个例不等于机制。
