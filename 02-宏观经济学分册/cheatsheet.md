# 速查表（宏观）

## 核心公式
| 场景 | 内容 |
|---|---|
| 支出法 | GDP = C + I + G + NX |
| 平减指数 | 名义 GDP ÷ 实际 GDP × 100 |
| CPI | 当期篮子成本 ÷ 基期篮子成本 × 100 |
| 实际利率 | ≈ 名义利率 − 通胀率 |
| 70 法则 | 翻倍年数 ≈ 70 ÷ 增长率（%） |
| 储蓄 | S = Y − C − G；封闭经济 S = I |
| 开放经济 | NX = S − I = NCF |
| 实际汇率 | 名义汇率 × 国内物价 ÷ 国外物价 |
| 货币乘数 | 1 ÷ 准备金率 |
| 货币数量方程 | M × V = P × Y |
| 费雪效应 | 名义利率 ≈ 实际利率 + 通胀率 |
| 现值 | PV = FV ÷ (1+r)^n |
| 支出乘数 | 1 ÷ (1 − MPC) |
| 税收乘数 | −MPC ÷ (1 − MPC) |
| 牺牲率 | 降 1 个百分点通胀对应的年度产出损失百分比 |

## 定量示例（全书统一）
- 名义 GDP 550、实际 385 → 平减指数 142.9，价格比基年高约 43%。
- 篮子基年 14 元、当期 20 元 → CPI ≈ 142.9。
- M 增 20%、Y 增 3% → 物价涨约 16.5%。
- 准备金率 10% → 乘数 10，1000 元存款支撑 10000 元。
- MPC = 0.8 → 支出乘数 5、税收乘数 −4；政府购买 100 亿 → +500 亿。
- 实际汇率：7 × 110 ÷ 100 = 7.7。

## 传导链速查
- **货币扩张**：货币供给↑ → 利率↓ → 投资↑ → AD 右移 → 产量与物价↑（短期）。
- **财政赤字**：借款↑ → 利率↑ → 投资↓（挤出）；开放经济中再加：资本净流出↓ → 本币↑ → NX↓。
- **贸易政策**：进口↓ → 本币↑ → 出口↓ → NX 不变。
- **资本外逃**：本币↓ + 利率↑。
- **供给冲击**：SRAS 左移 → 滞胀 → 政策两难。

## 判断流程
1. 先定位时间尺度：长期还是短期？
2. 再看是需求侧还是供给侧冲击？
3. 需要恒等式帮忙判断"总量能不能变"。
4. 最后考虑预期与时滞，决定政策力度。
