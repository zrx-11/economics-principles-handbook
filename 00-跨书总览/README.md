# 跨书总览：曼昆《经济学原理（第 7 版）》两册学习路线

## 推荐学习顺序
| 顺序 | 书 | 为什么在这个位置 | 能力里程碑 |
|---|---|---|---|
| 1 | 微观经济学分册（第 1–22 章） | 先建立"价格如何协调资源"的基本模型：供需、弹性、剩余、成本、市场结构。这些是宏观里"总需求为什么向下""乘数为什么收敛"的前置 | 能独立分析一个价格干预或税收政策的收益与代价 |
| 2 | 宏观经济学分册（第 23–36 章） | 在微观的个体决策之上加总：先学测量（GDP、CPI），再分长期（生产率、货币）与短期（AD-AS、政策）两条线 | 能判断一项货币或财政政策在短期与长期各有什么后果 |

**为什么不是反过来**：宏观的总需求曲线、乘数、可贷资金市场，全都建立在"个体按边际决策""价格传递信号"这些微观结论上。先宏观后微观会出现大量"结论记住了但推不出来"的情况。

## 各书定位（一句话）
- **微观**：讲单个市场、单个企业、单个消费者的决策与效率；覆盖外部性、垄断、信息不对称等市场失灵，不适合用来理解总量波动。
- **宏观**：讲加总之后的产出、物价、就业与国际收支；长于解释趋势与周期，不适合用来分析具体行业的价格与竞争。

## 两册的衔接点
| 微观概念 | 宏观里长什么样 | 衔接章节 |
|---|---|---|
| 供需均衡 | 外汇市场、可贷资金市场的均衡 | 微观 ch04 → 宏观 ch32 |
| 弹性 | 税负分摊、政策效果强弱 | 微观 ch05、ch08 → 宏观 ch34 |
| 剩余与无谓损失 | 税收楔子的效率代价、垄断损失 | 微观 ch07、ch08 → 宏观 ch30（通胀成本） |
| 边际成本与边际收益 | 投资决策（利率与预期回报比较） | 微观 ch13、ch14 → 宏观 ch26、ch27 |
| 机会成本 | 储蓄与消费的取舍、现值贴现 | 微观 ch01 → 宏观 ch27 |
| 要素市场与工资 | 失业的结构性来源、效率工资 | 微观 ch18、ch19 → 宏观 ch28 |
| 信息不对称 | 保险市场的逆向选择与道德风险 | 微观 ch22 → 宏观 ch27 |

## 学习节奏建议
- 每周 4–6 小时：微观每章约 1.5–2.5 小时，宏观每章 1.5–3 小时。
- 先按各书学习路径走完，再回看"跨书概念映射表"做交叉复习——同一个概念在两本书里的用法不同，交叉看最能发现理解漏洞。
- 每学完一篇（微观 7 篇、宏观 6 篇），做一次该篇的自测汇总；学完整册做"综合检验建议"里的整合题。
- 复习节奏：学完当天过一遍抽认卡，第 2 天、第 7 天各再一遍，只过标记"不熟"的。

## 总入口
打开根目录的 `index.html`，顶部切换两本书与跨书总览；每本书的进度独立保存。也可以单独把某一册的 `*学习伴侣.html` 发给别人，它自带全部章节、测验、卡片与术语。
